# file-converter-tool
A simple browser-based file converter tool to convert images to JPG,PNG,WEBP format . No backend needed . It is very useful and logical .
## 🚀 FEATURES
- Convert images to JPG , PNG , WEBP
- 100% browser-based-No data uploaded to server
- Drag & Drop support
- Fast and secure
- Mobile friendly

  ## 🛠️🛠️ TECH STACK 
  -HTML5
  CSS3
  JavaScript (Canvas API )

  ## 📃📃 HOW TO USE 
  1. OPEN **index.html** in browser
  2. Upload your image
  3. Select target format
  4. Click convert & Download
 
  ## 🌐 LIVE DEMO
  Enable GitHub pages from Settings> pages > Deploy from main branch
